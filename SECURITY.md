# Security Policy

## Supported versions

Security fixes target the latest stable version of @rentnerkev/menu published on npm. Older releases and prereleases are not maintained for security fixes; upgrade to the latest stable version before checking whether a problem persists. The version on the default branch may be unreleased.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/RentnerKev/RentnerMenu/security/advisories/new) to report suspected vulnerabilities to the repository maintainer, @RentnerKev. Do not disclose vulnerabilities in public issues, pull requests, or discussions before a coordinated disclosure.

Include the affected package version, a minimal reproduction or proof of concept, the security impact, and any suggested mitigation. Explain the relevant browser, React version, and application setup. Share only the information needed to reproduce the issue; remove credentials, personal data, and unrelated private application code.

The maintainer will assess the report and coordinate remediation and disclosure through the private advisory. There is no guaranteed response or fix deadline and no stated bug bounty. Please keep sensitive details private while a report is being investigated.

For ordinary bugs, feature requests, and usage questions, see [Support](.github/SUPPORT.md).
